How to Publish Your Website Using GitHub Pages

Learn how to host your static website for free directly from your GitHub repository.

What is GitHub Pages?

GitHub Pages is a free service provided by GitHub that allows you to host static websites directly from your GitHub repository. It's a great way to publish personal portfolios, project documentation, or small web applications.

What You'll Need

  • A GitHub account
  • A web browser
  • Basic knowledge of HTML and CSS
  • Git installed on your local machine (optional, but recommended for development)

Steps to Publish Your Website

Step 1: Create a New GitHub Repository

Go to github.com/new and create a new repository. Give it a descriptive name (e.g., my-website). You can choose to initialize it with a README, but it's not strictly necessary.

Step 2: Create Your Website Files

On your local machine, create a new folder for your project. Inside this folder, create your website files. At minimum, you'll need an index.html file. For example:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Awesome Website</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Hello, GitHub Pages!</h1>
  <p>This is my first website hosted on GitHub Pages.</p>
  <script src="script.js"></script>
</body>
</html>

You can also create a style.css and script.js if you want more complex styling and interactivity.

Step 3: Push Your Files to GitHub

Open your terminal or command prompt, navigate to your project folder, and initialize it as a Git repository (if you haven't already cloned an existing one):

git init
git add .
git commit -m "Initial website files"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git push -u origin main

Replace YOUR_USERNAME and YOUR_REPOSITORY_NAME with your actual GitHub username and repository name.

Step 4: Enable GitHub Pages

  1. Go to your repository on GitHub.
  2. Click on the "Settings" tab.
  3. In the left sidebar, click on "Pages".
  4. Under "Build and deployment", for "Source", select "Deploy from a branch".
  5. Under "Branch", select main (or master if that's what you used) and choose the /root folder.
  6. Click "Save".

GitHub will then deploy your website. This usually takes a few minutes.

Step 5: Access Your Live Website

After a few minutes, refresh the GitHub Pages section under "Settings > Pages". You should see a message indicating "Your site is published at https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/". Click on the link to view your live website!

Tips and Tricks

  • For user/organization pages (YOUR_USERNAME.github.io), create a repository named exactly YOUR_USERNAME.github.io. The content will be published directly from the main branch.
  • You can use a custom domain name with GitHub Pages.
  • GitHub Pages supports Jekyll for blogging and more complex site generation.
